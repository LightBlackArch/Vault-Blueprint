folder. This vault's startup instructions live in one place, `CLAUDE.md`, at
this same root. Nothing in them is Claude-only.

1. Read `CLAUDE.md` completely and follow it exactly. It names the files to
   read, in order, and what to do if the vault isn't set up yet.
2. Never read or write anything under `Privat/`.

way: change the instructions there, never here, so there is only one copy.
