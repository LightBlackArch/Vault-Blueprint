# The deny-list scan in blueprint-release.py refuses to ship anything that
# names the author. A handful of places have to name the author — you can't
# publish a repo without its own URL in it, and MIT requires a copyright line.
# Those exceptions live here, one per line, each with a reason.
#
# Format:   <path glob> :: <regex that is allowed to match there>
#
# NOTHING ELSE. If you find yourself wanting to add a line here to silence a
# hit, stop and ask whether the file should be saying that at all. This file
# is where a real leak would hide, so it stays short enough to read in ten
# seconds. Every entry needs a comment saying why.

# The repo URL. A self-updating project has to know where it lives, and the

* :: github\.com/eduardkuncek
